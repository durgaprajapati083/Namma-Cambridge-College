🚀 About the Project
Namma Cambridge is a cross-platform mobile solution designed to unify the digital experience across the various campuses of the Cambridge Group of Institutions, Bengaluru. The app serves as a central hub for academic resources, campus selection, and institutional updates.

🔑 Key Features
Role-Based Persistent Authentication: Secure login flow using Firebase Auth with automatic redirection for three distinct roles:

Students: Access to academic dashboards and specialization details.

Faculty: Dedicated portal for institutional management.

Visitors: Anonymous entry via a custom Email-OTP verification system to explore campus info.

Multi-Campus Navigation: Dedicated modules for CIT Main Campus, CIT North, Cambridge PU College, and more.

Modern UI/UX: Built with a clean, aesthetic design featuring glassmorphism, custom 3D assets, and responsive layouts.

Real-time Integration: Powered by Firebase Firestore for dynamic data and Cloudinary for optimized media hosting.

🛠 Tech Stack
Frontend: Flutter (Dart)

Backend: Firebase (Authentication, Firestore)

Media: Cloudinary API

Security: SMTP-based OTP Verification (Email-OTP)
